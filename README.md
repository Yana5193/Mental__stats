# mental_stats

Веб-система мониторинга психологического состояния сотрудников организации. Позволяет выявить уровень стресса и эмоционального выгорания через периодическое тестирование.

## Предварительные требования

| Инструмент | Минимальная версия |
|---|---|
| Python | 3.11 |
| Docker | 24.0 |
| Docker Compose | 2.24 |
| make | GNU Make 4.x (Windows: через Git Bash или WSL) |

## Быстрый старт

```bash
# 1. Клонировать и перейти в папку
git clone https://github.com/Yana5193/Mental__stats.git
cd Mental__stats

# 2. Установить зависимости локально (для тестов)
make setup

# 3. Запустить все сервисы
make run
# Открыть в браузере: http://localhost

# 4. Запустить тесты
make test

# 5. Посмотреть покрытие
make coverage
```

> **Примечание:** В Docker-образе `psych_analyzer` устанавливается напрямую с TestPyPI.
> Локально `make setup` ставит библиотеку из папки `shared_lib/` в editable-режиме.

## Структура проекта

```
mental_stats/
├── frontend/               # HTML/CSS/JS страницы (nginx :80)
├── shared_lib/             # Исходники psych-analyzer (публикуется на TestPyPI)
├── backend/
│   ├── app/                # [Сервис 1] Главный бэкенд — порт 8000
│   ├── questions_service/  # [Сервис 2] Микросервис вопросов — порт 8001
│   └── notification_service/ # [Сервис 3] Микросервис уведомлений — порт 8002
├── docs/                   # Спецификация, архитектура, диаграммы
├── docker-compose.yml
└── Makefile
```

## Все команды

```bash
make help               # список команд
make setup              # установить зависимости
make test               # все тесты
make test-lib           # тесты только shared_lib
make coverage           # отчёт о покрытии
make build-lib          # собрать пакет psych-analyzer
make install-lib-local  # установить пакет локально
make docs               # показать структуру документации
make run                # запустить через docker compose
make compose-up         # собрать и запустить контейнеры
make compose-down       # остановить контейнеры
make check              # полная проверка (test + build-lib)
make clean              # удалить временные файлы
```

## Роли пользователей

- **Сотрудник** — проходит психологический тест раз в 30 дней
- **Психолог** — просматривает аналитику с баллами и статусами, добавляет тесты и вопросы
- **Менеджер** — просматривает факт прохождения, добавляет сотрудников
