# Доменная модель

## Сущности

### Employee
Сотрудник организации, проходящий психологическое тестирование.

| Поле | Тип | Описание |
|------|-----|----------|
| emp_id | int | Уникальный идентификатор сотрудника |
| full_name | str | ФИО сотрудника |
| position | str | Должность |
| dept_id | int | Ссылка на отдел |
| password | str | Пароль для входа |

---

### Department
Отдел организации, к которому относится сотрудник.

| Поле | Тип | Описание |
|------|-----|----------|
| id | int | Уникальный идентификатор отдела |
| tittle | str | Название отдела |

---

### StaffStatus
Результат прохождения психологического теста сотрудником.

| Поле | Тип | Описание |
|------|-----|----------|
| id | int | Уникальный идентификатор записи |
| emp_id | int | Ссылка на сотрудника |
| total_points | int | Итоговый балл теста |
| status | str | Статус (Норма / В зоне риска / Нужна беседа) |
| advice | str | Рекомендация по результату |
| date_passed | datetime | Дата и время прохождения теста |

---

## Бизнес-правила

### Периодичность тестирования
- Сотрудник может проходить тест **не чаще одного раза в 30 дней**
- Повторная попытка раньше срока → `429 Too Many Requests`
- Константа: `RETEST_PERIOD_DAYS = 30`

### Интерпретация результата

| Баллы | Статус |
|-------|--------|
| 0 – 15 | Норма |
| 16 – 30 | В зоне риска |
| 31 и выше | Нужна беседа |

### Валидация ответов

**Монотонный паттерн:**
- Если **80% и более** ответов одинаковы — тест невалиден
- Ответ: `422 Unprocessable Entity`

**Противоречивые ответы:**
- Тест содержит пары семантически похожих вопросов (`consistency_pairs`)
- Если в **2 и более парах** разница между ответами превышает допустимую — тест невалиден
- Ответ: `422 Unprocessable Entity`

---

## Глоссарий

| Термин | Описание |
|--------|----------|
| `emp_id` | Уникальный числовой идентификатор сотрудника в системе |
| `consistency_pairs` | Список пар индексов вопросов, проверяющих схожие утверждения. Пример: `[[0, 8], [1, 9]]` — вопросы 0 и 8 должны получить близкие ответы |
| `RETEST_PERIOD_DAYS` | Минимальный интервал в днях между двумя прохождениями теста. Значение: `30` |
